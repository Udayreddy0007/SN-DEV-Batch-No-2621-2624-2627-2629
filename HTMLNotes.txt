--> HTML : Hypertext Markup Language 
        
       What is HTML ?

       -> HTML is used to create the structure and content of web page  and it will display the content

          For example, HTML tells the browser:
          
          This is a heading  --- 
          This is a paragraph
          This is an image
          This is a link
          This is a list
          This is a table
          Display a form
   
   NOTE: HTML is not a programming language. It is a markup language.

       -> Features of html

            -- it is a easy language to learn -- beginners  can create webpages quickly
            -- Platform independent -- it can run on different OS such as windows , linux , Mac
            -- Create a webpage structure
            -- Supports multimedia  -- we can display images , audio and video
            -- Creates hyperlinks - it will allow a user to navigate between webpages
            -- works with CSS 
            -- Works with js
